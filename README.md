# The Geologic History of Southern California

A small site walking through how Southern California's landscape formed, from the old subduction zone to the San Andreas Fault and the Ice Age.

Live site: https://bebopkenny.github.io/The-geologic-history-of-Southern-California/

## Running it locally

```
npm install
npm run dev
```

Pushing to `main` builds and deploys to GitHub Pages automatically.
